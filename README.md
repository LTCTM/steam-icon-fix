# steam-icon-fix

一个用于修复 Windows 上 Steam 游戏快捷方式图标缺失的小工具。

## 用途

Steam 安装的游戏有时会在桌面或开始菜单的快捷方式上显示空白/损坏图标。本程序会读取 Steam 客户端自己维护的本地数据，找出所有真正已安装的游戏，并检查它们对应的图标文件是否缺失。如果缺失，就从 Steam 的 CDN 下载正确的图标并刷新 Windows 图标缓存。

## 工作流程

1. **定位 Steam 安装位置**
   从 Windows 注册表读取 Steam 的安装路径，避免硬编码到某个固定盘符或目录。

2. **找出所有 Steam 库**
   Steam 允许在多个磁盘上建立游戏库。程序读取 Steam 的库配置文件，解析出所有库目录，这样即使游戏分散在 C 盘、D 盘或其他磁盘上也不会漏掉。

3. **读取已安装游戏清单**
   Steam 每安装一个游戏，都会在该库目录下生成一个清单文件。只要存在这个清单文件，就表示这款游戏处于“已安装”状态。程序会扫描所有库里的这些清单文件，汇总出完整的已安装游戏列表。

4. **获取图标哈希**
   每个游戏的图标哈希存放在 Steam 的全量应用元数据缓存里。程序会在这里查找每个已安装游戏对应的客户端图标哈希。

5. **下载图标**
   拿到图标哈希后，程序会并行地从 Steam CDN 下载缺失的图标文件，保存到 Steam 自己的图标目录中。

6. **刷新图标缓存**
   下载完成后，程序会清空 Windows 图标缓存，让资源管理器重新加载图标，使修复立即生效。

## 使用方式

直接运行对应语言的可执行文件或脚本即可。程序会自动完成上述全部步骤，无需手动指定路径。

目前提供两个实现版本：Python 和 Go，功能一致，可按需选择。

## 注意事项

- 运行过程中会短暂结束并重新启动资源管理器进程，以刷新图标缓存，这是正常现象。
- 如果某款游戏在 Steam 元数据中没有客户端图标哈希，则该游戏不会被修复。
- 程序只读取 Steam 本地文件，不会修改游戏文件或 Steam 配置，也不会读取 Steam 账号的任何信息。
